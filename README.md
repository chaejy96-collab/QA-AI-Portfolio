# QA AI Portfolio

이 저장소는 QA 엔지니어링 프로세스를 자동화하고 지능화하기 위한 멀티 에이전트 시스템 포트폴리오입니다. 실제 환경(Jira, Figma, GitHub, 외부 LLM API)을 연동하는 대신, 모든 입력을 합성(Synthetic) 데이터로 대체하여 에이전트의 판단 논리와 파이프라인의 견고함을 검증합니다.

## 프로젝트 구성

### 1. [AI 결함 검증 에이전트](./ai-defect-verification-agent/)
*   **목적**: Jira 결함 수정 여부를 검증.
*   **핵심 도구 전략**: Jira(Atlassian MCP)를 활용한 맥락 분석 및 Playwright 자동화 테스트.
*   **보고 전략**: Jira REST API를 통한 안전한 결과 반영 및 Dry-run 모드 기반의 자동화 리포팅.

### 2. [AI 테스트케이스 에이전트](./ai-test-case-agent/)
*   **목적**: Figma 설계 및 요구사항 기반 테스트케이스 자동 설계.
*   **핵심 도구 전략**: Figma MCP 및 REST API를 활용한 가용성 확보 및 다단계 검증 파이프라인.
*   **핵심 전략**: 검증 실패 시 최종 산출물 생성을 차단하는 Fail-fast 방식의 빌드 게이트.

## 보안 및 데이터 경계

이 포트폴리오는 다음과 같은 보안 기준을 엄격히 준수합니다.

- **합성 데이터**: 모든 입력값(Jira, Figma, 코드, 요구사항)은 실제 회사의 자산이 아닌 합성(Synthetic) 데이터입니다.
- **외부 차단**: 실제 Jira, Figma, GitHub API, 사내 시스템, 외부 LLM/Opus API를 호출하지 않습니다.
- **로컬 실행**: 모든 환경은 로컬에서 실행되며, API Key나 사내 계정 정보를 포함하지 않습니다.
