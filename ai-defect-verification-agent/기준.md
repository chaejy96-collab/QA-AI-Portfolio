# 포트폴리오 데모 검증 기준

> 이 문서는 과거 실험에서 사용한 원본 `기준.md`가 아니다. 원본의 내용은 현재 확인할 수 없으므로, 아래는 합성 데모를 위해 새로 정의한 기준이다.

- C1: 사용자가 저장을 요청하면 화면에 `Profile saved` 성공 메시지가 표시되어야 한다.
- C2: 저장 요청은 `POST /api/profile`로 전송되고 HTTP 200 응답을 받아야 한다.
- C3: `수정 확인` 판정에는 성공 메시지와 API 응답을 보여 주는 실행 관찰값, 스크린샷, trace, 동영상 증거가 모두 있어야 한다.
